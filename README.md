# FO Authority — Birthday Musical Concert

Starter project structure for the FO Authority birthday concert website.

## Project structure
- `index.html` — main landing page
- `register.html` — guest registration / ticket selection page
- `styles.css` — global design system and shared components
- `animations.css` — motion and animation styles
- `script.js` — shared site interactions
- `register.js` — registration form interactions and validation
- `assets/images/` — event photography and graphics
- `assets/audio/` — optional audio assets
- `assets/icons/` — logos and icon assets
- `assets/fonts/` — locally hosted fonts
- `admin/` — future private admin dashboard
- `backend/` — Supabase client configuration placeholder

## Run locally
Open this folder in VS Code. For local development, use the VS Code Live Server extension and open `index.html`.

## Important
This is a clean starter scaffold, not a finished production website. Registration is not connected to a database yet. Do not collect real guest information until the backend, privacy notice, validation, and access controls are implemented.
